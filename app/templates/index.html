About This Project

Multi-Label Classification for Pharmacovigilance

This web application uses advanced machine learning techniques to predict potential side effects of drugs based on their chemical and pharmacological characteristics (ATC codes and drug names).

Key Features:
  • Multi-Label Classification: Predicts multiple side effects simultaneously
  • Model Comparison: Three models evaluated (Logistic Regression, Random Forest, MLP)
  • Interpretability: Feature importance analysis reveals which drug characteristics drive predictions
  • Real-time Inference: Instant predictions with probability scores
Data Sources:
  • SIDER: Side Effect Resource
  • DrugBank: Drug database
  • ATC: Classification system
  • MedDRA: Medical dictionary
Disclaimer: This tool is for educational and research purposes only. Always consult healthcare professionals for medical advice.
